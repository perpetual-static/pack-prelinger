# Prelinger Pack

A channel pack for [Retro Cable Box](https://perpetual-static.github.io/retro-cable-box/). Ephemeral films from the Prelinger Archives: driver's ed, the world of tomorrow, and social guidance.

## Install

Ask your agent:

> Install the plugin from perpetual-static/pack-prelinger.

The box adds the channels below and plays the films from archive.org. When a
new release of this repo adds channels, the box adds them in its nightly check.
